**Architecture:**
- **Rendering.** Cache Components is on. Pages are prerendered from the DB at build time. Catalogue reads go through `'use cache'` wrappers in `src/lib/catalogue/cached.ts`, tagged `catalogue`. `revalidateCatalogue()` expires that tag with no stale window.
- **Styling.**
  - Tailwind 4 `@theme` carries `tokens.css` verbatim (fonts excepted).
  - The world's CSS is ported from `store.css`, `site.css` and `flows.css` as plain CSS in `@layer components`, keeping the prototype's class names, so every rule stays diffable against the prototype.
  - Site-wide partials live in `src/styles/` and are imported by `globals.css`. Home, film, catalogue and auth CSS is co-located with its components.
- **Client islands.** Client code is limited to the store header (search, account pill, cart pill, announcement), the cart controls, toast, the carousel controller, the rail controls, the film engine, and login.
  - The film engine is a faithful TypeScript port of the v2 `site.js` engine: one passive scroll listener, one rAF tick, `--ti`/`--to` written to 4 decimals, transform and opacity only. Its pure progress math is unit-tested.
  - The carousel has its own small controller (no Swiper): a pure reducer plus a hook.
  - The login dialog is imported on first open.

**Tech Stack:** Next.js 16.4 App Router (Cache Components, `next/font/local`, `next/image` with `getImageProps` for art direction, AVIF), React 19.3, TypeScript 6.0 strict, Tailwind CSS 4 (`@tailwindcss/postcss`), shadcn/ui (`dialog`, `input-otp` only), `subset-font` and `fontkit`, Vitest 5 (`unit`, `ui` on happy-dom with Testing Library, `int` on MongoMemoryReplSet), Playwright 1.65 (Chromium; it also drives `scripts/shoot.mjs`), GitHub Actions.
